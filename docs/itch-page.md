## Title and tagline

**Shiftland**: Move the earth. Make everyone happy.

## Short description

Slide tectonic plates to raise mountains and let the sea in. A tiny island puzzle for GitHub Game Off 2026.

## Body

A small island is cut into tectonic plates. Slide one along its rail:

- where it **pushes** into its neighbour, the land rises into mountains;
- where it **pulls away**, the sea pours in.

Goats want peaks. Villages want to stay low and whole. Lighthouses want a coast. Buoys want open sea. Oases want a still lake, and penguins want a floe by the water. Make them all happy at once in as few shifts as you can.

- 26 islands across meadow, coast, desert, tundra and a finale
- every level is solver-checked: it can always be solved, and par is the true minimum
- free undo and restart; a live preview shows what a shift will do before you let go
- hints when you are stuck: the first points at a plate, the second shows the move
- stars for finishing at par without seeing a move, never required
- plays in the browser with mouse, keyboard or touch, in about an hour

**Controls:** drag a plate along its rail, or select it and use the arrow keys. Z undo, R restart, H hint, M map.

**Accessibility:** colour-blind safe plate patterns, a reduced-motion setting, no time pressure.

## Made for GitHub Game Off 2026 (theme: SHIFT)

Source: github.com/vsolano9/shiftland. All rights reserved: the code is public to read because the jam asks for it, it is not open source.

**How it was made.** The game was designed and coded by an AI coding agent (Claude), directed by Victor, who picked the concept from the agent's shortlist, played it and approved each release step. Its code and text are AI-written. All art and sound in the game are generated by that code at runtime (three.js geometry and shaders, WebAudio synthesis); there are no image, model or audio files made by generative AI in the build. Concept images used during development were made with an image model and are not part of the game.
