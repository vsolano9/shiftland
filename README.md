# Shiftland

A tectonic-shift puzzle for [GitHub Game Off 2026](https://itch.io/jam/game-off-2026) (theme: SHIFT).

**Play it in the browser:** https://thechosenvictor.itch.io/shiftland

A small island is cut into tectonic plates. Slide one along its rail: where it pushes into its neighbour the land rises into mountains, and where it pulls away the sea pours in. Goats want peaks, villages want to stay low and whole, lighthouses want a coast, buoys want open sea, oases want a still lake and penguins want a floe by the water. Make them all happy at once, in as few shifts as you can.

- 26 islands across meadow, coast, desert, tundra and a finale
- every island is solver-checked: it can always be solved, and par is the true minimum
- free undo and restart, a live preview of each shift, and hints when you are stuck
- mouse, keyboard or touch: drag a plate along its rail, or select it and use the arrow keys. Z undo, R restart, H hint, M map

## How it was made

The game was designed and coded by an AI coding agent (Claude), directed by Victor, who picked the concept from the agent's shortlist, played it and approved each release step. All art and sound in the game are generated by code at runtime (three.js geometry and shaders, WebAudio synthesis); there are no image, model or audio files made by generative AI in the build. The images in `concepts/` were made with an image model as references during development and are not part of the game.

## Build and test

In `game/` (Node 22.18+ or 24):

| Command | What |
| --- | --- |
| `npm install`, then `npm run dev` | Run the game locally |
| `npm test`, `npm run typecheck` | Unit tests and types |
| `npm run e2e` | Build, then Playwright against the served build |
| `node scripts/fullplay.mjs [mouse\|touch\|keys] [WxH]` | After a build: play every island at par by real input, from a clean save to the ending |
| `node scripts/monkey.mjs [steps] [seed] [WxH]` | After a build: random real input with state checks |
| `npm run press` | Build, then render the itch screenshots, banner and splash |
| `npm run pack:check` | Build the itch zip and check it |
| `npm run levels:audit` | Check every island against the quality bar with the solver |
| `npm run levels:export` | Write `src/levels/levels.json` from `src/levels/campaign.ts` |
| `node src/solver/cli.ts inspect <name or number>` | Map, shortest solutions and what each first move costs |

## Layout

| Path | What |
| --- | --- |
| `game/src/rules` | Rules and the move diff, shared by the game, the solver and the tests |
| `game/src/solver` | Solver, audit, generator, hint worker, CLI |
| `game/src/levels` | Island specs and the built level JSON |
| `game/src/game` | Play layer with no DOM: session, controller, progress, key and drag input |
| `game/src/render`, `game/src/audio`, `game/src/ui` | Code-made art, sound and interface |
| `docs/` | Working notes kept during development: `PLAN.md`, `design-plates.md`, `qa.md` (play record), `release.md`, `research.md`, `concepts.md`, `itch-page.md` |
| `press/` | Cover and screenshots, rendered from the game |
| `spikes/` | Throwaway rules spikes from before the game was chosen |
